# Data availability

The integrated BasinGraph reproducibility dataset v3.1.0 is openly available
at https://doi.org/10.5281/zenodo.20791231 under CC BY 4.0. It contains the
complete Track A-D/C evidence package, raw return archives, observer or detailed
logs, independently derived analyses, validation reports, source identities,
Source Data, Supplementary Information, publication figures, claim-boundary
documentation and SHA-256 integrity records.

The registered evidence extensions comprise 1,920 mechanism-ablation runs,
3,840 modern-baseline runs, 1,440 `bbob-largescale` runs, 60 sequential
overhead runs, 2,310 scientific-model and NIST observed-data runs, and 18
separately reported task-specific reference runs. Favorable, null and
unfavorable outcomes are retained.

The original prospective COCO/BBOB and CUTEst evidence remains available in the
version 2.0.0 reproducibility dataset at
https://doi.org/10.5281/zenodo.20788903. Development partitions, confirmatory
partitions and historical materials are identified separately and are not
pooled retrospectively.

Six NIST Statistical Reference Dataset files included in Track C retain their
source URLs, retrieval mirror commit and SHA-256 identities. The certified
parameter vectors were used only to construct shared bounded standardized
coordinates; the NIST experiments are reference-data calibration anchors, not
blind deployment tests.
