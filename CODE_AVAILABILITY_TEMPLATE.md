# Code availability

The BasinGraph source code, benchmark runners, analysis scripts and
figure-generation scripts are openly available at
https://github.com/xwxkj/BasinGraph under the BSD-3-Clause licence.

The immutable result-bearing implementation used for the reported prospective
COCO/BBOB and CUTEst experiments is available at tag
`route-b-v2.0.0-rc1-selected-final-candidate`, commit
`adbc0ecdf1153044188f0508321c47001ad9bdb0`, and is archived at
https://doi.org/10.5281/zenodo.20789002. Its frozen options hash is
`031b9c3df716889e48e2db753c73ec960b96a0239173ce791b4ed1ee63ed0f69`.

Later repository releases may update documentation, packaging and independent
evidence-extension runners without altering the result-bearing optimizer or
the original prospective records.
