# Code availability

The BasinGraph source code, benchmark runners, analysis scripts and
figure-generation scripts are openly available at
https://github.com/xwxkj/BasinGraph under the BSD-3-Clause licence.

The current version-specific software archive is BasinGraph v3.1.0 at
https://doi.org/10.5281/zenodo.21857175. Its archived source snapshot is
identified by release-source commit
`2084438e679f61660de497f5464fbe5636373163`.

The immutable result-bearing optimizer used throughout the reported evidence is
BasinGraph 2.0.0-rc1, available at tag
`route-b-v2.0.0-rc1-selected-final-candidate`, candidate commit
`adbc0ecdf1153044188f0508321c47001ad9bdb0`, and package `basingraph_v2/`.
Its frozen options hash is
`031b9c3df716889e48e2db753c73ec960b96a0239173ce791b4ed1ee63ed0f69`.
The original result-bearing software archive remains available at
https://doi.org/10.5281/zenodo.20789002.

The registered Track A-D/C evidence-extension runners and protocols do not
alter the frozen optimizer. Transparent Python ports of L-SHADE 1.0.1, jSO and
L-SRTDE are identified as ports rather than byte-identical official
executables; their provenance and registered deviations are reported in the
repository and Supplementary Information.
