# BasinGraph v3.0.0

## Release scope

This was a documentation and archive-composition release.

The result-bearing optimizer remained BasinGraph 2.0.0-rc1. No optimizer
source, frozen option, benchmark run, raw result, statistical analysis or
numerical conclusion was changed.

## Evidence available at that release

- prospective COCO/BBOB holdout;
- prospective CUTEst holdout;
- final Source Data and analysis outputs;
- manuscript-aligned protocols and documentation.

Legacy validation and applied-problem benchmark materials were excluded from
the release archive.
