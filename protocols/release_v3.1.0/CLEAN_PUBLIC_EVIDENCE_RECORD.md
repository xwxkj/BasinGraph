# BasinGraph v3.1.0 clean public evidence record

Status: **published and verified**  
Preferred submission-facing DOI: `10.5281/zenodo.21863259`  
Complete priority/provenance DOI: `10.5281/zenodo.20791231`

## Purpose

The clean public evidence record is the preferred reproducibility citation for
the journal submission. It contains the scientific evidence needed to inspect,
reproduce and audit the reported results without exposing author manuscripts or
internal submission-management material.

## Included

- Track A, B, C and D raw return archives;
- observer and detailed execution logs;
- independently derived analyses;
- Source Data;
- Supplementary Information;
- main and supplementary figures;
- editable figure source;
- validation, source-identity and provenance reports;
- SHA-256 manifests.

## Excluded

- author manuscripts;
- redline and clean submission copies;
- Cover Letters and responses to reviewers;
- internal claim-audit or editorial-readiness documents;
- internal submission packages;
- credential, DOI-reservation and deposition-management files.

## Relationship to the complete record

The complete record remains public and unchanged at
`10.5281/zenodo.20791231`. It preserves the earliest full timestamped priority
and provenance trail. The clean record is an independent curated edition; no
code, data, protocol, run, statistic, figure or numerical conclusion differs
between the two records.

## Permanent public-release rule

Future Zenodo and GitHub public packages must be built from an explicit
scientific-evidence allowlist. Packaging must stop if a path or file name
contains manuscript, redline, submission, Cover Letter, response to reviewers,
rebuttal, internal claim audit, credential, token or deposition-management
material.
